# ZADDY Breadcrumbs 2026
ZINE / SPELLBOOK — static web edition
LICENSE: Creative Commons

## what it is
A cyberpunk spellbook zine built as a single-page web reader. It collects 25 pages of breadcrumbs, experiments, and notes into one portable HTML reader with inline audio and YouTube embeds.

## live / local
- open `index.html` directly in a browser
- pages load from local markdown files in `book-ZADDY-breadcrumbs-2026-collection/`
- audios live in `audios/`
- assets live in `assets/`

## reader features
- left sidebar navigation
- top style switcher: default / ZADDY / DAB / GDK
- inline play buttons for audio and YouTube
- dark void base with neon magenta/cyan accents

## repo hygiene
- built PDFs / exports should stay outside git or under `products/`
- see `.gitignore` for ignored paths
